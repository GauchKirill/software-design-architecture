# ADR-0002: Strategy и Decorator для расчёта итога

- **Статус:** принято
- **Контекст:** итог должен считаться из оценок и рубрикатора; возможны разные правила (взвешенное
  среднее, взвешенные баллы), а также требование округления с настраиваемой точностью.

## Решение

1. Формула итога — `FinalScorePolicy` (Strategy) с реализациями:
   - `WeightedAveragePolicy` — нормирует каждый критерий на его максимум, затем усредняет по весам;
   - `WeightedPointsPolicy` — суммирует абсолютные взвешенные баллы и делит на взвешенный максимум.
2. Округление — `RoundedFinalScorePolicy` (Decorator), оборачивающий любую стратегию; число знаков
   задаётся конфигурацией (0..4).
3. `FinalScoreCalculator` (Domain Service) проверяет согласованность входных данных и делегирует
   формулу политике. Неоценённый критерий даёт 0 баллов; результат содержит `assessed/total`.
4. Выбор формулы и декоратора — в composition root (`--formula`, `--rounding`); домен не знает
   про CLI и про то, какая стратегия выбрана.

## Обоснование

- Новое правило итога добавляется новым классом, без правки калькулятора (OCP).
- Округление — сквозная модификация результата, а не свойство формулы; Decorator не дублирует
  `std::round` в каждой стратегии и композируется.
- Политики возвращают `FinalScore` 0..100, поэтому подтипы не нарушают контракт (LSP); это
  проверяется тестом `FinalScorePolicyTest.DecoratorRoundsResultAndKeepsContract`.

## Последствия

- Композиция политик — цепочка объектов; при большом числе декораторов усложняется чтение графа.
- По умолчанию включено округление до одного знака; «сырой» результат доступен через тесты политик
  и может быть включён новой конфигурацией.
- Добавление стратегии требует ветки выбора в composition root; это осознанная точка расширения,
  а не «массовая правка».

## Альтернативы

- **`enum` + `if/switch` в калькуляторе** — отвергнуто: нарушает OCP, смешивает правила и расчёт.
- **Флаг округления в каждой стратегии** — отвергнуто: дублирование и риск расхождения.
- **Хранить итог в БД** — отвергнуто: см. ADR-0001.
